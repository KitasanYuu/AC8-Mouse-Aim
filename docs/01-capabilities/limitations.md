# 已知限制与排查（Limitations）

## 版本相关

- **游戏更新后失效**：原生模块包含与版本相关的输入、镜头偏移，校验不通过时拒绝启用。请先切换到联机原版模式，等待对应版本支持；不要移除校验。
- **其他模组冲突**：安装层面可以共存（见[安装与卸载](../03-usage/installation.md#与其他模组共存)），功能层面不保证。同时修改输入、镜头、覆盖层或共用 UE4SS 的模组仍可能互相干扰。

## 显示

- **看不到瞄准圈**：检查指示层开关键（默认 F7）；改用无边框窗口模式，独占全屏下桌面覆盖层可能不可见。暂停、注视、自动驾驶期间隐藏是预期行为。
- **开局是座舱视角**：游戏把上次使用的视角保存在存档中，开局沿用。切到追尾镜头并正常结束任务后，下次开局即为追尾镜头。模组不修改该设置。

## 操作

- **部分演出未让出**：状态检测不保证覆盖所有剧情演出。请说明任务和触发位置，需要时按镜头状态采集键（默认 F6）采集记录。
- **按键与游戏冲突**：模组不屏蔽游戏的按键绑定。在调参面板的 Key Config 页给模组换键，或调整游戏键位。
- **手柄的手动接管**：规则与键盘相同，尚未实测。
- **调参面板的飞控参数**：只影响接近瞄准点的最后阶段，大机动中由机体本身的能力决定，差别不易察觉。测试时做 5–20° 的小幅修正与跟踪。

## 启动与崩溃

- **启动失败、黑屏或崩溃**：退出游戏，用 `AC8MouseFlight.cmd` 切换到联机原版模式；反馈游戏版本和日志，不要混用不同版本的文件。日志位置见[性能问题反馈](../03-usage/performance-reporting.md#日志位置)。
