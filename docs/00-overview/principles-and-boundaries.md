# 原则与边界（Principles & Boundaries）

本文件定义本项目不可越过的边界。[能力矩阵](../01-capabilities/capability-matrix.md)中标记为 `Out-of-Scope` 的条目，其依据均来自本文件。

## 1. 执行玩家意图

- 飞控执行玩家的指向，不替玩家做决定。不设防撞地、防失速、过载限制或倒飞限制；低空下压、大迎角、失速机动都由玩家判断。
- 唯一的“保护”只改变到达方式，不改变瞄准点：例如低空快速下沉时，不再用推杆去够侧上方的瞄准点，改为先翻滚再拉杆。瞄准点始终由玩家决定。
- 不为某一类空战场景（如对 Su-34 一类目标的缠斗）单独调参而牺牲通用手感。
- 判断依据是实测的机体模型和用时比较，不是人为偏好。

## 2. 不改变游戏本身

- 只写入玩家的操纵输入轴和最终画面视角；不修改气动、推力、伤害、AI 或存档。
- 游戏自己的功能优先：注视、剧情演出、自动驾驶期间让出操控与镜头；模组不覆盖游戏的按键绑定，冲突时由玩家改键。
- 游戏的设置（如保存的视角模式）由游戏管理，模组不代为修改。

## 3. 离线与安全

- 仅用于离线单人模式；离线启动标记缺失时原生模块拒绝运行。
- 原生模块校验游戏可执行文件、加载器和关键代码签名，不匹配时拒绝启用，不通过移除校验来适配未知版本。
- 运行时探测只读：读取反射字段、内存中的数据表与本地化文字；不解包游戏资源，不提取加密密钥。
- 仓库不包含游戏资产或游戏可执行文件；从游戏读取的数据（机体参数表、设置菜单文字等）只在本机使用，不提交。
- 离线运行依赖 Steam 启动参数中的 `EOS_USE_ANTICHEATCLIENTNULL=1` 与本模组的反作弊设置文件 `AC8MouseAim_Offline.json`。进入多人模式前必须退出游戏，用 `AC8MouseFlight.cmd` 切换到联机原版模式并清空该启动参数；关闭鼠标辅助、卸载本模组都不能代替这一步，因为其他共用加载器的模组仍可能加载。
- 项目不提供任何联网兼容性或账号安全保证。

## 4. 配置与开发

- 游戏中安装的 `config.ini` 的 `[tuning]` 段就是开发调参用的配置，仓库默认值必须与之一致，不另设“游戏配置”一栏。
- 模组的所有按键都可配置（`[keys]`），玩家可见的文字都可本地化（`Scripts/lang`），不在代码中写死。
- 修改飞控或镜头时，保留已经稳定的更新时序；行为变更先改[飞控规范](../02-architecture/flight-control.md)，并通过闭环仿真。
