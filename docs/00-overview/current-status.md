# 当前状态（Current Status）

> 2026-10-07 状态快照。权威能力清单以[能力矩阵](../01-capabilities/capability-matrix.md)为准。
> 游戏内结论来自开发者本机：Windows x64，3440×1440 无边框窗口，ACE COMBAT 8 Steam Build 25201480；不外推到其他硬件或游戏版本。

## 版本

- 原生模块与脚本基于 0.2.30（同帧数值桥接、性能专项）；之后的改动在开发分支上，尚未发布新版本号。
- 依赖仓库随附的 RE-UE4SS；原生模块校验加载器版本与游戏关键签名。

## 已在游戏中使用验证

- 鼠标辅助：升力矢量规则、到位制动与改平、低空下沉时的拉起方式、精细选杆。
- 追尾镜头与座舱／机首视角（鼠标摇杆、朝瞄准圈转头、自由视角），视角交接的过渡。
- 让出：注视（长按锁定）、剧情演出、开场镜头；自动驾驶按游戏自身状态识别，按住期间让出，松开后瞄准点回到机首。
- 手动接管：读取游戏的俯仰、翻滚、平移输入，达到一半以上才视为玩家操作（游戏的鼠标操控只产生 0.1–0.2）。
- 调参面板：Settings 与 Key Config 两页，写回 `config.ini` 并立即生效；按键录制；简体中文与英文界面，语言跟随游戏。
- 视野角度增减与设置变化时的平滑过渡。

## 仅自动检查或验证不足
