# 项目概览（Project Overview）

## 定位

AC8 MouseFlight 为 **ACE COMBAT 8 离线单人模式**提供 War Thunder 式的鼠标指向飞控：玩家用鼠标指定瞄准点，飞控按升力矢量规则把机首带过去。模组只替换玩家的操纵输入并修正镜头，不修改游戏的飞行模型、推力、武器或存档。

本项目为非官方模组，与游戏开发商、发行商及 War Thunder 无关联。

## 组成

| 部分 | 作用 |
|---|---|
| 鼠标辅助 | 瞄准点保存在世界坐标中；飞控每帧决定俯仰、翻滚、平移的杆量，详见[飞控规范](../02-architecture/flight-control.md) |
| 追尾镜头 | 模组接管游戏的追尾镜头，平滑转向瞄准点，保留游戏随速度变化的视野角度 |
| 座舱／机首视角 | 保留游戏的镜头位置，鼠标以“鼠标摇杆”方式工作，视角可按设置朝瞄准圈转头 |
| 指示层 | 桌面透明覆盖层：瞄准圈、机首标记、提示文字与调参面板 |
| 让出 | 注视、剧情演出、自动驾驶期间交还操控与镜头 |
| 调参面板 | 游戏内调整常用设置与按键，写回 `config.ini` 并立即生效 |
| 开发工具 | 飞行重建（遥测）、飞控对比台、性能统计 |

## 运行方式

```text
UE4SS Lua 脚本（每帧）
  读取机体姿态、位置、镜头、游戏输入 ─┐
                                      ▼
原生模块 ac8_mouse_aim_010.dll
  鼠标原始输入 → 瞄准点 → 飞控 → 写入游戏的输入轴
  镜头更新之后修正最终画面视角
  指示层窗口绘制瞄准圈与面板
```

各部分的实现见[总体架构](../02-architecture/architecture.md)。

## 适用范围

- 平台：Windows x64，ACE COMBAT 8 Steam 版。
- 游戏版本：原生模块校验游戏可执行文件的签名，只在已适配的版本上启用。
- 模式：仅离线单人。多人模式的切换要求见[原则与边界](principles-and-boundaries.md#3-离线与安全)。
