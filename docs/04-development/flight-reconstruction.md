# 飞行重建（Flight Reconstruction）

`dev\Telemetry.cmd` 启动一个本地服务（只用 Python 标准库），并在浏览器打开 `http://127.0.0.1:8731/`。

## 开启遥测

在游戏中 `config.ini` 的 `[control]` 设置 `telemetry_port=49731`。模组每帧向 127.0.0.1 发送一个 UDP 数据包，不等待、不阻塞，没有服务接收时直接丢弃；设为 0 即关闭。

## 内容

- **实时重建**：三维追尾视角（机首、速度方向、瞄准点、轨迹）、俯视航迹，速度、高度、攻角、侧滑、过载、角速度、杆量与加速／减速输入，以及最近 20 秒的曲线。
- **他机**：每秒 10 次记录附近飞机（最多 1000 架，分包发送）的位置、姿态、速度和血量，以及游戏自己的锁定候选标记（可锁定、暂不可锁定；友军不可锁定，据此区分敌我）。大型机的可锁定部位只在被选中时记录。头目、头目护卫和精英约每秒 30 次记录，LADON 还记录可变后掠翼的后掠与下折角。
- **命中事件**：游戏报出的机炮命中与伤害、攻击方。
- **输入**：模组写入的俯仰、翻滚杆量与游戏的 `InputPitch`、`InputRoll`，用于核对手动接管的识别。
- **录像**：每次飞行自动录制到仓库的 `recordings/`（不提交），页面左上角可选择回放、拖动与变速。录像也用于拟合机体模型与飞控对比台的场景。

机体被游戏重新放置（开局、补给、重生）时，轨迹在跳变处断开，曲线在新片段的前 3 秒不画，以免出现长直线与速度尖峰。

## 运行时探测

遥测开启时自动执行，不占按键：

- **机体几何**：每种玩家机体出场 5 秒后采集一次，LADON 与 Moon 11 第一次出现时各采集一次，写出 `Scripts/mesh-probe-*.json`：组件、网格引用、相对变换、包围盒、骨骼位置与反射层可读的碰撞形状。只读，不解包游戏资源。`dev/compare/build_model.py` 由此生成对比台的机体粗模。

另有 **LOD 记录**（不依赖遥测，始终运行）：机身网格每级 LOD 的切换阈值与引擎 LOD 设置在每架飞机出场时写入 UE4SS.log 一次，之后每 3 秒在有变化时记录当前 LOD、镜头距离与视野角度。
