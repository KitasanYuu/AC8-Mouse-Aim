# 机动范式规范

本文件定义鼠标指向飞控“应当怎样飞”。代码实现位于 `src/maneuver.h`（机动选择）与 `src/flight_logic.h`（杆量整形），参数可在 `config.ini` 的 `[tuning]` 段覆盖。行为规则修改应先改本文件，并通过 `check.cmd` 中的闭环仿真。

## 原则

1. **对齐 War Thunder 鼠标指向**：鼠标给出世界方向，飞机以实际最快的滚转/俯仰组合把机头带过去。不内置具名机动库，破 S、殷麦曼、斜筋斗、直接下压等都是同一规则在不同目标方位下的自然结果。
2. **执行意图，不替玩家做决定**：控制器不设禁止项，不做防撞地、防失速、过载限制或倒飞限制。低空下压、大迎角、过失速、高 G 转弯等都由玩家判断。ACE 系列机体性能超出现实战斗机，控制器不得以“保护”为由削减杆量。
3. **按实测机体决策**：拉杆还是推杆、是否先翻正，按实测模型估算的用时比较，不用人为偏好。
4. **只在几何歧义处做选择**：规则只在数学上无法唯一确定方向时给出偏好，并在机动完成前锁定，避免来回翻转。

## 实测机体模型（2026-10-03 标定，Build 25201480，平飞）

| 轴 | 延迟 | 动态 | 满杆能力 | 输入曲线 |
| --- | --- | --- | --- | --- |
| 俯仰 | 约 0.4 s | 一阶，时间常数约 0.8 s | 拉 61°/s、推 26°/s（气动），重力项 ±9°/s | 约 \|u\|^1.1 |
| 滚转 | 约 0.2 s | 加速度受限，满杆约 250°/s² | 上限约 150°/s | 加速度约 \|u\|^1.6 |

重力项：正飞时重力使机头下沉（拉杆变慢、推杆变快），倒飞时相反。因此正飞推杆约为拉杆的 2/3，倒飞推杆更弱。标定方法见 `calibrate` 参数；游戏版本变化后应重新标定。

### 按机型在线辨识

不同机型差异很大（实测：某较弱机型俯仰权限约 ×0.65、响应更慢，滚转加速度约 121 vs 286°/s²，滚转延迟多约 0.06 s）。上表模型只作为先验，飞行中按机型在线辨识：

- **多模型并行（输出误差法）**：一组候选模型（权限倍率 × 响应时间常数 × 额外延迟）用实际发出的杆量、经过与测量相同的延迟、游戏输入平滑和主机角速度滤波并行运行；取近期（`ident_memory` 秒）与实测角速度最吻合的模型，接近的候选按代价加权平均，使估计平滑变化。不对角速度求导，不受滤波滞后与噪声偏置。最小二乘法曾在仿真中因时间错位严重漂移，已弃用。
- 辨识出的权限、时间常数、延迟同时用于杆量整形（预测、制动、反解）和拉/推选择的用时估算。
- 累计 `ident_trust` 秒有效数据前按标定值飞行，之后平滑过渡到辨识值。键盘接管期间不学习。
- 暂停、回中、卡顿等重置控制状态时保留辨识结果；换机（主 DLL 通知）时重置为先验重新辨识。
- 日志每 5 秒记录一行 `ident:`（俯仰拉/推、时间常数、额外延迟，滚转加速度、时间常数、额外延迟，已用数据量）。
- 仿真以三种机体验证：标定机型、按日志辨识的较弱机型、刻意加长延迟的迟钝机型；标定机型与较弱机型均须收敛且过冲 < 3°。

## 量的定义

机体坐标：前 `f`、右 `r`、上 `u`。目标方向在机体系的分量为 `fx, rx, ux`。

| 量 | 定义 | 含义 |
| --- | --- | --- |
| θ | `acos(fx)` | 机头与目标的夹角 |
| 拉杆滚转角 | `atan2(rx, ux)` | 使目标位于座舱正上方所需的滚转，正值向右滚 |
| 推杆滚转角 | `atan2(-rx, -ux)` | 使目标位于机腹正下方所需的滚转 |
| 俯仰面误差 | `atan2(ux, fx)` | 目标在机体俯仰平面内的角度，可超过 90° |
| 横向误差 | `atan2(rx, fx)` | 方向舵修正量 |

## 机动选择

2026-10-04 重写：原来按“近场 / 机动承诺 / 改出锁定 / 保持 / 追击 / 正飞上限”等多层状态叠加，状态之间互相牵制，目标一变就要等旧状态切换完，机动中连圈都对不快（反馈）。现在**任何距离都用同一条规则，每帧只按当前几何重新决定**，不锁定任何机动；唯一的记忆是二选一处的滞回（拉/推、±180° 滚转方向、受限升力保持在哪一侧、正后方掉头方向），都不会延迟对新目标的响应。

### 统一规则

- **滚转**：让座舱（拉杆）朝向目标；目标接近机腹正下方时让机腹朝向目标（推杆）。
- **坡度上限**（相对地平线）：
  - 正飞优先：拉杆时坡度最多 `slice_bank`（90°）；离目标 `slice_from`～2×`slice_from`（20°～40°）之间放宽到 `slice_deep`（135°，大转弯中边拉边让机头往下切）；离目标 `invert_min_angle`（120°）起再放宽，150° 时可倒飞（破 S）。小幅的左下/右下修正因此是“滚转 + 拉杆 + 偏航”，不会机腹朝上。
  - 已经压着的大坡度（斜切中、筋斗顶部）不会因为离目标变近被一下砍到上限，而是允许“当前坡度 − `slice_ease`”（最多 `slice_hold`），逐步放平。原来上限随角度骤降，斜切到一半就滚回水平改推杆，仿真中在离目标约 14° 处停了 1 秒。
  - 到达时机翼放平：坡度最多为（剩余角度 − `level_inside`）× `level_per_deg`。离目标 5° 时最多 80°，2° 时 20°，1° 以内保持机翼水平。几度的横向偏差因此靠“压坡度 + 拉杆”快速消掉，而不是机翼几乎水平只靠很弱的方向舵慢慢挪（实测 5° 横向偏差要 2–3 秒）。
- **推杆**：满足任一条件即推杆：
  - 目标离拉杆可用的（受限）升力方向超过 `push_below`（60°，退出 45°）：机翼回正、机腹朝向目标。原来此时停在坡度上限，只剩方向舵在动，仿真中卡在离目标 6° 或 30° 处。
  - 目标接近机腹正下方（把机腹转向目标所需滚转小于 `push_roll_enter`），且按估算用时推杆更快：倒飞时推杆能力几乎为零，会半滚后拉杆。
  - 目标在持续移动（追击，超过 `pursuit_speed`）时不用第一条，以免下降转弯的目标被改成推杆。
- **俯仰**：从第一帧就和滚转一起动。按“杆量生效时滚转已到达的姿态”计算目标在座舱方向上的分量：滚转预计在俯仰延迟内完成的部分（最多 `overlap_max`，离目标 15° 内逐步取消、5° 内为 0）算作已完成。远处（≥ `far_start`）按升力方向上的角度乘以对准程度的余弦拉杆，近处（≤ `near_end`）按目标在座舱方向上的偏差，可推杆。
- **方向舵**：始终负责俯仰平面以外的部分：近处是机翼方向的偏差，转弯中是受限升力平面以外的部分（例如坡度受限时目标偏下的那部分）。

### 正后方歧义（θ > 160° 进入，θ < 145° 退出）

目标几乎正对机尾时，滚转方向对鼠标微小抖动极度敏感。此时：

- 采用**斜向上掉头**：滚转使升力方向位于“世界上方偏向一侧 50°”，然后满杆拉。
- 偏向哪一侧取进入时目标最后所在的左右侧；锁定到退出。
- 机头接近垂直时世界水平无意义，保持当前滚转直接拉。

## 杆量整形（基于模型）

每轴每帧：

1. **延迟预测（Smith 预估）**：用实测模型回放最近一个延迟时长内已发出但尚未体现在实测角速度上的指令，得到延迟后的角速度及期间转过的角度，用剩余误差决策。
2. **期望角速度**：取三者最小值——满杆能力（×0.9）、按反向能力仍能在目标处停住的最大角速度、最后几度的线性收敛（`*_gain`）。俯仰的制动按一阶模型精确计算（拉起时只能靠较弱的推杆刹停，因此提前收杆），滚转按加速度受限计算。`*_brake` 为制动能力的保守系数。
3. **模型反解**：以 `*_track` 的时间常数追踪期望角速度，按模型反解出所需加速度/稳态值，再经实测输入曲线反算杆量。部分杆量因此有准确效果，无需旧的整体指数补偿。
4. **俯仰配平**：在近场对小误差积分（`pitch_trim`，1.0），补偿模型与重力的残差，使准星能收敛到中心。积分值在机动中保留（`pitch_trim_keep`=1）：原来每次机动都衰减归零，到位后从头积累，准星稳定在目标上方约 0.7°（实测）。
5. **角速度观测器**：预测与修正不直接使用带噪声的实测角速度，而是用模型推算并以 `rate_observer`（1/s）向实测值校正的估计值。实战中直接使用实测值导致目标附近杆量每分钟换向约 100 次（游戏输入平滑掩盖了大部分晃动，但机头仍在目标附近漂移约 2°）；仿真加入 2°/s 测量噪声即可复现，加观测器后换向回到无噪声水平，到达时间和过冲不变。
6. **实时舵效估计**：实战中满杆拉的俯仰角速度中位数仅 37–40°/s（校准巡航时约 61°/s），舵效随速度在数秒内变化。模型偏强时会高估已发杆量带来的俯仰，于是在转弯中途满杆推杆刹车、停下再拉（实测“一顿一顿”）。做法：用延迟后的杆量驱动“单位舵效”模型响应，与实测角速度一起经 `authority_filter` 秒低通（避免把时间常数误差当成舵效误差），按 `authority_memory` 秒遗忘做最小二乘，得到俯仰和滚转的舵效倍率；只采纳估计变化的 `authority_trust`（全信任时，比模型更迟钝的机体会被误判为偏弱并过冲），限制在 `authority_min`–`authority_max`（上限 2.0：高 G 机动时实测俯仰约为模型的 2 倍）。

参数由 `tests/flight_sim.cpp` 的闭环仿真评估：仿真以实测模型和一个刻意更慢更弱的模型分别飞标准机动，要求标称模型下所有机动收敛且过冲 < 3°。默认值偏向响应速度（标称模型过冲约 1.5° 以内）；若实机过冲明显，先降低 `*_brake`。用法：`build\flight_sim.exe pitch_brake=0.4 ...` 查看任意参数组合的逐项结果，`build\flight_sim.exe sweep` 扫参。

键盘 WASDQE 超控规则不变：按下即由玩家直接接管对应轴；W/S 同时暂停自动滚转。AutoPilot（同时按 Q+E）期间模组让出全部控制，Q+E 再按或移动鼠标即接管。

## 调参入口

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| `near_end` / `far_start` | 3° / 20° | 俯仰与方向舵：远处按升力方向拉杆，近处按座舱/机翼方向的偏差，之间平滑过渡 |
| `level_per_deg` / `level_inside` | 20 / 1° | 到达时机翼放平：坡度最多为（剩余角度 − 1°）× 20；1° 以内机翼水平 |
| `chase_level` | 0（关） | 1：目标在机头前移动（超过 `pursuit_speed`，即在追一架机动的敌机）时取消上面的放平上限，升力面一直对准目标。录像中机炮追击时，这个上限让升力面对不上敌机，拉杆把机头带偏，敌机滑到座舱侧面（2026-10-05 在游戏内试验中） |
| `ground_guard` | 5 s | 低空保护：按当前下沉率几秒内会到海平面、瞄准点又高于机头时：不再用推杆去够瞄准点（除非机腹朝上、推杆的力朝上），并在滚转的同时按座舱朝上的程度先拉杆（越近越强）；瞄准点仍完全由玩家决定，瞄准点低于机头时不干预。0 = 关闭。高度是海拔，山地上空不起作用。录像（2026-10-05）：650 m/s、480 m、下沉 280 m/s 时瞄准点上抬，飞控在 80° 坡度下推杆去够侧上方的瞄准点，浪费了拉起所需的 0.5 s 后撞海 |
| `rollout_rate` / `rollout_lag` | 0（关）/ 0.25 s | 可选：按“还有多久到达”再限制坡度。仿真中开启后在离目标约 18° 处骤然改平，拉杆把机头带到目标上方，默认关闭 |
| `slice_bank` / `slice_deep` / `slice_from` | 90° / 135° / 20° | 拉杆坡度上限：小修正 90°，离目标 40° 以上可到 135°（斜切） |
| `invert_min_angle` | 120° | 离目标超过此角度才允许座舱转到地平线以下更深（150° 时可倒飞） |
| `slice_ease` / `slice_hold` | 10° / 135° | 已压着的大坡度逐步放平：允许当前坡度减 10°（最多 135°） |
| `push_below` / `push_below_exit` | 60° / 45° | 目标离可用升力超过此角度时改为回正推杆 |
| `push_roll_enter` / `push_roll_exit` | 30° / 50° | 目标接近机腹正下方时才按用时比较考虑推杆 |
| `push_enter` / `push_exit` | 120° / 135° | 允许推杆的误差范围（滞回） |
| `choice_margin` / `push_bias` | 0.6 s / 0.3 s | 推杆比拉杆慢多少仍可选择 / 推杆中改拉所需的用时节省 |
| `pursuit_speed` | 4°/s | 目标移动快于此值（2 倍时完全）视为追击：不因目标偏下而改推杆 |
| `overlap_max` | 30° | 滚转中提前开始拉杆时，最多把多少“尚未完成的滚转”算作已完成；离目标 15° 内逐步取消。按全速滚转预支约 80° 时曾出现持续螺旋（实测） |
| `tail_enter` / `tail_exit` / `tail_bank` | 160° / 145° / 50° | 正后方掉头 |
| `latch_limit` | 150° | ±180° 滚转方向锁定的释放阈值 |
| `lead_gain` / `lead_filter` / `lead_max` | 1.0 / 0.2 s / 60°/s | 目标自身移动速度的前馈：目标在机头俯仰/偏航方向上移动多快，就先按这个速度跟，再叠加修偏差的量 |
| `authority_memory` / `authority_filter` / `authority_trust` | 2 s / 1 s / 0.6 | 实时舵效估计（0 = 关闭） |
| `pitch_unload` | 0 | 减缓仍需的俯仰时最多使用的反向能力比例（0 = 不限） |
| `pitch_*` / `roll_*`（模型） | 见上表 | 实测机体模型；`pitch_gravity` 0.3（正飞回中杆时游戏保持机头，约 1900 帧实测中位 −0.2°/s；原 1.5 使准星稳定在目标上方 0.4–0.7°） |
| `pitch_track` / `roll_track` | 0.10 / 0.12 s | 角速度追踪时间常数 |
| `pitch_brake` / `roll_brake` | 0.55 / 0.45 | 制动能力保守系数（越小越早收杆） |
| `pitch_gain` / `roll_gain` | 2.5 / 2.0 | 最后阶段的收敛速度（1/s）；俯仰 2 时离目标约 40° 就开始减速（实测），3 时过冲 |
| `pitch_gain_near` | 0.4 | 最后约 4° 内俯仰增益逐渐提高到 (1+0.4) 倍，避免最后 1–2° 慢慢挪进圈 |
| `pitch_release` | 0.10 s | 杆量回中或反打时游戏的输入平滑（加杆为 `pitch_input`）；按 120 次实测满推刹车拟合，刹车距离与停止预测都用它 |
| `push_gravity` | 6.5 | 推杆能力随正立程度增加的量（°/s） |
| `pitch_trim` / `pitch_trim_limit` | 0.5 / 4°/s | 俯仰配平积分 |
| `calibrate` | 0 | 改为新的正数即运行一次输入标定 |

遥测日志每 10 秒记录一次状态；按 F4 开关逐帧飞行记录（`TRACE` 行，含期望/预测角速度）。

**自动机动记录**（`auto_trace`，默认 0 关闭；调试时设为 1 记录每次机动，2 记录每一帧）：机头偏离目标超过 4° 时自动开始，1° 以内持续 2 秒后停止，每帧一行 `AT`，字段依次为：帧间隔、θ、对准权重、正后方、推杆、俯仰误差、滚转误差、滚转角、俯仰角速度、滚转角速度、俯仰杆量、滚转杆量、期望俯仰/滚转角速度、预测俯仰/滚转角速度、键盘接管位、必然俯仰（°）、俯仰/滚转舵效倍率。
