# 机动范式规范

本文件定义鼠标指向飞控“应当怎样飞”。代码实现位于 `src/maneuver.h`（机动选择）与 `src/flight_logic.h`（杆量整形），参数可在 `config.ini` 的 `[tuning]` 段覆盖。行为规则修改应先改本文件，并通过 `check.cmd` 中的闭环仿真。

## 原则

1. **对齐 War Thunder 鼠标指向**：鼠标给出世界方向，飞机以实际最快的滚转/俯仰组合把机头带过去。不内置具名机动库，破 S、殷麦曼、斜筋斗、直接下压等都是同一规则在不同目标方位下的自然结果。
2. **执行意图，不替玩家做决定**：控制器不设禁止项，不做防撞地、防失速、过载限制或倒飞限制。低空下压、大迎角、过失速、高 G 转弯等都由玩家判断。ACE 系列机体性能超出现实战斗机，控制器不得以“保护”为由削减杆量。
3. **按实测机体决策**：拉杆还是推杆、是否先翻正，按实测模型估算的用时比较，不用人为偏好。
4. **只在几何歧义处做选择**：规则只在数学上无法唯一确定方向时给出偏好，并在机动完成前锁定，避免来回翻转。

## 实测机体模型（2026-10-03 标定，Build 25201480，平飞）

| 轴 | 延迟 | 动态 | 满杆能力 | 输入曲线 |
| --- | --- | --- | --- | --- |
| 俯仰 | 约 0.4 s | 一阶，时间常数约 0.8 s | 拉 61°/s、推 26°/s（气动），重力项 ±9°/s | 约 \|u\|^1.1 |
| 滚转 | 约 0.2 s | 加速度受限，满杆约 250°/s² | 上限约 150°/s | 加速度约 \|u\|^1.6 |

重力项：正飞时重力使机头下沉（拉杆变慢、推杆变快），倒飞时相反。因此正飞推杆约为拉杆的 2/3，倒飞推杆更弱。标定方法见 `calibrate` 参数；游戏版本变化后应重新标定。

## 量的定义

机体坐标：前 `f`、右 `r`、上 `u`。目标方向在机体系的分量为 `fx, rx, ux`。

| 量 | 定义 | 含义 |
| --- | --- | --- |
| θ | `acos(fx)` | 机头与目标的夹角 |
| 拉杆滚转角 | `atan2(rx, ux)` | 使目标位于座舱正上方所需的滚转，正值向右滚 |
| 推杆滚转角 | `atan2(-rx, -ux)` | 使目标位于机腹正下方所需的滚转 |
| 俯仰面误差 | `atan2(ux, fx)` | 目标在机体俯仰平面内的角度，可超过 90° |
| 横向误差 | `atan2(rx, fx)` | 方向舵修正量 |

## 机动选择

### 近场跟踪（θ < 3°，3°～12° 平滑过渡；仅用于从目标附近开始的小修正）

- **按水平侧向偏差压坡度**：坡度 = 目标相对地平线的左右偏差 × `near_bank_gain`，上限 `near_bank_max`。偏差以世界坐标度量，压坡度不会抵消自身需求；偏差收敛时机翼自然回到水平。
- 不在近场为对准升力方向而大幅滚转：机头掠过目标时小偏差的方向变化极快，按方向滚转会造成左右摇晃（实测）。
- 俯仰修正上下偏差，可推杆。方向舵修正左右偏差，随过渡淡出。
- 机头接近垂直时世界水平无意义，改为保持当前滚转。
- **机动承诺与提前改出**：误差一旦超过 `far_start`（大机动），就保持拉/推对准，不按近场规则提前改平（实测会在圈外减速并留下二次修正）。改平时机按模型计算：预计到达剩余时间小于“改平所需滚转时间 × `rollout_lead`”时开始改出，使机头到达时机翼基本已平；到达时若俯仰仍在转动则先保持坡度，俯仰停下后再改平（避免剩余俯仰运动被滚转带成横向漂移）。倒飞时同样适用。

### 对准与拉/推选择（θ ≥ 12° 完全生效）

- 滚转使目标位于座舱上方（拉杆）或机腹下方（推杆），再沿俯仰方向带到目标。过渡在二维方向向量上混合，避免角度跨越 ±180° 时出现反向滚转。
- **按估算用时选择拉或推**：用时 = 滚转用时（含延迟、加速、制动）+ 俯仰用时（含延迟与建立时间，按滚转后姿态的拉/推能力及重力计算）。只有推杆快 `choice_margin` 秒以上才切换，反之亦然。
- **推杆仅限目标在机翼平面下方**：推杆滚转角 < 70° 才可选择推杆，> 85° 立即放弃；绝不为推杆而反向滚离侧方目标（实测会造成摇晃）。
- θ > `push_exit` 一律滚转后拉杆。
- 远离目标时俯仰只沿所选方向，滚转未对准前按 `pull_full`/`pull_none` 限制俯仰。
- 目标在机体正下方附近（滚转需求接近 ±180°）时左右等价：滚转方向一旦选定就锁定，直到剩余量回到 150° 以内。

### 正后方歧义（θ > 160° 进入，θ < 145° 退出）

目标几乎正对机尾时，滚转方向对鼠标微小抖动极度敏感。此时：

- 采用**斜向上掉头**：滚转使升力方向位于“世界上方偏向一侧 50°”，然后满杆拉。
- 偏向哪一侧取进入时目标最后所在的左右侧；锁定到退出。
- 机头接近垂直时世界水平无意义，保持当前滚转直接拉。

## 杆量整形（基于模型）

每轴每帧：

1. **延迟预测（Smith 预估）**：用实测模型回放最近一个延迟时长内已发出但尚未体现在实测角速度上的指令，得到延迟后的角速度及期间转过的角度，用剩余误差决策。
2. **期望角速度**：取三者最小值——满杆能力（×0.9）、按反向能力仍能在目标处停住的最大角速度、最后几度的线性收敛（`*_gain`）。俯仰的制动按一阶模型精确计算（拉起时只能靠较弱的推杆刹停，因此提前收杆），滚转按加速度受限计算。`*_brake` 为制动能力的保守系数。
3. **模型反解**：以 `*_track` 的时间常数追踪期望角速度，按模型反解出所需加速度/稳态值，再经实测输入曲线反算杆量。部分杆量因此有准确效果，无需旧的整体指数补偿。
4. **俯仰配平**：在近场对小误差积分，补偿模型与重力的残差，使准星能收敛到中心。

参数由 `tests/flight_sim.cpp` 的闭环仿真评估：仿真以实测模型和一个刻意更慢更弱的模型分别飞标准机动，要求标称模型下所有机动收敛且过冲 < 3°。默认值偏向响应速度（标称模型过冲约 1.5° 以内）；若实机过冲明显，先降低 `*_brake`。用法：`build\flight_sim.exe pitch_brake=0.4 ...` 查看任意参数组合的逐项结果，`build\flight_sim.exe sweep` 扫参。

键盘 WASDQE 超控规则不变：按下即由玩家直接接管对应轴；W/S 同时暂停自动滚转。AutoPilot（同时按 Q+E）期间模组让出全部控制，Q+E 再按或移动鼠标即接管。

## 调参入口

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| `near_end` / `far_start` | 3° / 12° | 近场跟踪与对准的过渡区间；超过 `far_start` 即进入机动承诺 |
| `near_bank_gain` / `near_bank_max` | 5 / 60° | 近场每度侧向偏差对应的坡度及上限 |
| `push_enter` / `push_exit` | 120° / 135° | 允许推杆的误差范围（滞回） |
| `choice_margin` | 0.25 s | 拉/推切换所需的用时节省 |
| `pull_full` / `pull_none` | 60° / 120° | 滚转未对准时的俯仰限制 |
| `tail_enter` / `tail_exit` / `tail_bank` | 160° / 145° / 50° | 正后方掉头 |
| `latch_limit` | 150° | ±180° 滚转方向锁定的释放阈值 |
| `rollout_lead` | 1.5 | 提前改出系数（0 = 到达后再改平） |
| `pitch_*` / `roll_*`（模型） | 见上表 | 实测机体模型 |
| `pitch_track` / `roll_track` | 0.10 / 0.12 s | 角速度追踪时间常数 |
| `pitch_brake` / `roll_brake` | 0.55 / 0.45 | 制动能力保守系数（越小越早收杆） |
| `pitch_gain` / `roll_gain` | 3.0 / 3.0 | 最后几度的收敛速度（1/s） |
| `pitch_trim` / `pitch_trim_limit` | 0.5 / 4°/s | 俯仰配平积分 |
| `calibrate` | 0 | 改为新的正数即运行一次输入标定 |

遥测日志每 10 秒记录一次状态；按 F4 开关逐帧飞行记录（`TRACE` 行，含期望/预测角速度）。

**自动机动记录**（`auto_trace=1`，默认开启）：机头偏离目标超过 4° 时自动开始，1° 以内持续 2 秒后停止，每帧一行 `AT`，字段依次为：帧间隔、θ、对准权重、正后方、推杆、俯仰误差、滚转误差、滚转角、俯仰角速度、滚转角速度、俯仰杆量、滚转杆量、期望俯仰/滚转角速度、预测俯仰/滚转角速度、键盘接管位。
