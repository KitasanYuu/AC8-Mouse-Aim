# 安装与卸载（Installation）

所有操作都通过仓库根目录的 **`AC8MouseFlight.cmd`** 完成。它通过 Steam 的安装记录找到游戏（找不到时请手动选择），打开后是一个菜单：

```text
==== AC8 MouseFlight ====
游戏目录：...\steamapps\common\ACE COMBAT 8
状态：已安装，离线 MOD 模式
Steam 启动参数：已设置

  1  更新 / 修复
  2  切换到联机原版模式
  3  复制 Steam 启动参数
  4  卸载
  0  退出
```

## 安装

1. 完全退出游戏，下载（或 `git clone`）本仓库。
2. 运行 `AC8MouseFlight.cmd`，选择 **1**。
3. 首次安装需设置 Steam 启动参数。安装结束时若检测到尚未设置，会把参数复制到剪贴板：Steam 库 → 右键 ACE COMBAT 8 → 属性 → 通用 → 启动选项，粘贴：

   ```text
   cmd /d /c "set EOS_USE_ANTICHEATCLIENTNULL=1&& %command% -anticheat_settings=AC8MouseAim_Offline.json"
   ```

   原有其他启动选项请先备份。工具只读取 Steam 设置以判断是否已填写，不会修改它。

4. 从 Steam 启动游戏，在游戏设置中选择 EXPERT 操作类型，进入单人任务。建议使用无边框窗口：指示层是桌面透明覆盖层，独占全屏下可能不可见。

工具会校验复制后的关键文件；校验失败时应检查安装，而不是关闭校验。

## 更新

拉取最新代码后运行 `AC8MouseFlight.cmd`，选择 **1**。`config.ini` 中 `[control]` 与 `[keys]` 段里改过的设置会保留；输入槽位、轴符号等版本适配项按新版本重置。旧版本 `[control]` 中的 `post_stall_key`、`tuning_key` 会迁移到 `[keys]` 的 `post_stall`、`tuning`。

## 游戏目录中的文件

游戏目录中只有模组本身：`Game/Binaries/Win64` 下的加载器、UE4SS 框架与 `UE4SS/Mods/AC8MouseAim`，以及 `EasyAntiCheat/AC8MouseAim_Offline.json`。工具、脚本和备份留在仓库目录，备份位于仓库的 `backups/`。旧版本留在游戏根目录的脚本和备份会在安装或更新时移到这里。

## 与其他模组共存

| 已有环境 | 处理方式 |
|---|---|
| 没有框架或冲突加载器 | 安装随附的 UE4SS 与本模组 |
| 已验证兼容的 UE4SS，默认 Mods 路径 | 保留框架、加载器、设置与其他模组，只安装本模组并合并启用列表 |
| 运行库不兼容、多个运行库、自定义路径或重定向 | 写入前停止并说明原因，由用户手动整合 |

兼容性按运行库校验值判断，而非版本名称；目前只自动支持 `Game/Binaries/Win64/UE4SS` 布局下已验证的运行库。复用模式不修复、替换或重新启用已有加载器。其他模组的启用状态及顺序保留，本模组条目合并到列表末尾；`mods.json` 的格式可能变化，其他字段和值保留。

这解决的是安装层面的共存，**不保证功能层面无冲突**。

## 切换到联机（原版）模式

退出游戏，运行 `AC8MouseFlight.cmd`，选择 **2**，在“离线 MOD”与“联机原版”之间切换：

- 切到联机原版：停用 `dwmapi.dll` 加载器，并提醒在 Steam 启动选项中清空本模组的离线参数。这会停用共用该加载器的所有模组；其他类型的加载器不在处理范围内。
- 切回离线 MOD：重新启用加载器；若 Steam 启动参数尚未填写，会复制到剪贴板。

进入多人模式前务必退出游戏，完成切换并清空启动参数；关闭鼠标辅助不能代替这一步。详见[原则与边界](../00-overview/principles-and-boundaries.md#3-离线与安全)。

## 回退版本

退出游戏，把仓库切回需要的版本（例如 `git checkout <提交或标签>`），再运行 `AC8MouseFlight.cmd` 选择 **1**。

## 卸载

退出游戏，运行 `AC8MouseFlight.cmd`，选择 **4**，然后在 Steam 启动选项中清空本项目的离线参数（检测到仍有该参数时会提醒）。

卸载只移走本模组并移除其启用项，保留其他模组。若没有其他模组，会询问是否同时移除 UE4SS 框架和加载器。移走的文件都在仓库的 `backups/` 中，可以恢复。**卸载本模组不等于禁用所有模组**，进入多人模式前需要单独确认。
