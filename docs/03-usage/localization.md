# 多语言（Localization）

## 语言的选择

- 调参面板与指示层的文字按 `[control] language` 选择：`auto`（默认）跟随游戏的界面语言，也可指定为某个语言文件的代码。也可在调参面板的“显示 → 语言”中切换。
- `auto` 时 Lua 在游戏启动和每次进入任务时读取引擎当前语言（如 `zh-Hans`、`en`），写入 UE4SS.log 的 `Game language` 一行。
- 没有对应文件时，先找同一语系的文件（如 `zh-Hant` 使用 `zh-Hans`），再退回英文。
- 目前提供英文（`en.txt`）与简体中文（`zh-Hans.txt`）。

日志、`config.ini` 的注释与开发文档面向开发者，保持英文或中文原样，不做本地化。

## 语言文件

位于 `Payload/Game/Binaries/Win64/UE4SS/Mods/AC8MouseAim/Scripts/lang/<代码>.txt`：

```text
# 注释
font = Microsoft YaHei UI
panel.title = MouseFlight 设置（{1}：关闭）
item.sensitivity = 鼠标灵敏度
item.sensitivity.desc = 指定以鼠标操作瞄准点时的灵敏度……
```

- UTF-8 编码，每行 `编号 = 文字`，`#` 开头为注释。
- `{1}`、`{2}`……由模组填入（按键名、数值等），必须保留。
- `font` 指定绘制用的字体，必须包含该语言的全部字符；中文、日文、韩文需要各自的字体。
- 编号分为：`hud.*`（指示层文字）、`panel.*`（面板固定文字）、`group.*`（分组标题）、`item.<键名>` 与 `item.<键名>.desc`（项目名称与说明）。
- 文件中缺少的编号显示代码中的英文。

## 新增语言

1. 复制 `en.txt` 为 `<代码>.txt`，代码与游戏报告的语言一致（如 `ja`、`ko`、`fr`、`de`）。
2. 翻译每行等号右侧，设置合适的 `font`。
3. 保存后在面板中切换语言即可生效，不需要重新编译。

`en.txt` 与 `zh-Hans.txt` 中的条目与代码中的英文一一对应；修改代码中的文字后，应同步更新这两个文件。

## 用语规范

- 玩家可见的用语与游戏自身设置菜单保持一致：中文说明以“设置……”“指定……”开头，按键项写作“设置用于……的按键”，开关值写作 ON/OFF；术语使用镜头、视野角度（FOV）、机首、翻滚、平移、高G力回转、机体等。统一用语见[文档总览](../README.md#术语)。
- 说明必须与实现一致：写明作用对象、单位、取值范围与适用模式（如“模式 3 专用”），不写面板无法达到的取值，不暗示某功能是唯一途径。
- 游戏的设置菜单文字可在运行时读取（`DT_MenuOptionConfig` 的文字编号，经 `LiveLocalizationManager:LocalizeString` 转换），作为用语参考；读取结果属于游戏数据，不提交。
- 面板尺寸按字号固定，不随语言、页面或选中项变化；放不下的文字截断，说明最多换三行。
