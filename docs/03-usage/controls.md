# 操作（Controls）

表中的模组按键均为默认值，全部可以修改，见[配置与调参面板](configuration.md#按键)。

## 飞行

| 操作 | 功能 |
|---|---|
| 移动鼠标 | 移动瞄准点；飞机把机首带向瞄准点 |
| 按住 F | 自由视角：鼠标只转动镜头，瞄准点不变 |
| 松开 F | 镜头平滑回到瞄准点。开启“自由视角后保持朝向”时，自由视角期间瞄准圈跟随镜头，松开时瞄准点移到镜头所朝方向（同 War Thunder） |
| 游戏的俯仰键（默认 W / S） | 手动接管俯仰，同时暂停自动翻滚 |
| 游戏的翻滚键（默认 A / D） | 手动接管翻滚 |
| 游戏的平移键（默认 Q / E） | 手动接管平移 |
| 按住游戏的自动驾驶（同时按住左右平移键，或专用键，默认 C） | 只在按住期间生效：模组让出操控与镜头，鼠标移动不计入；松开后瞄准点回到机首 |
| 鼠标后侧键 | 失速机动辅助：按住期间在 500 km/h 以下进行高G力回转，俯仰先回中约 0.04 秒再拉满，以符合游戏进入失速机动的条件；按住时瞄准圈外有一圈琥珀色 |
| F9 | 瞄准点回到机首 |
| F8 | 鼠标辅助 ON/OFF；OFF 时由游戏原本的操作控制机体 |
| F7 | 指示层 ON/OFF，飞行控制不受影响 |

手动接管按游戏读取到的俯仰、翻滚、平移输入判断，改过游戏键位同样有效，详见[输入与接管](../02-architecture/input-and-takeover.md)。

## 调参面板

| 操作（默认） | 功能 |
|---|---|
| F3 | 打开或关闭调参面板 |
| ↑ / ↓ | 选择上一项／下一项；最上面是页签行 |
| ← / → | 调整数值；在页签行上切换页面 |
| 按住 Shift | 以 1/5 步长调整 |
| Backspace | 还原为打开面板时的值 |
| Enter | 在 Key Config 页为选中项录制新按键（Esc 取消，Delete 清除） |

## 诊断

| 操作（默认） | 功能 |
|---|---|
| F10 | 重新读取 `config.ini` |
| F4 | 逐帧飞行记录（写入日志） |
| F5 | 性能统计（每 10 秒写入日志） |
| F6 | 镜头状态采集（最长 180 秒，排查用） |
| F7（机库中） | 读取当前机体参数表并写入文件 |
| F8（机库中） | 读取当前机体几何数据并写入文件 |

机库中的两项只在没有玩家机体时执行，任务中按下不会触发。

## 注视与剧情演出

- 长按锁定键约 0.35 秒后，模组让出镜头与操控，游戏的注视镜头转向目标或剧情点；短按切换目标不会让出。0.35 秒是模组的防误触门槛，不代表游戏内部阈值。
- 注视或已识别的剧情演出期间，模组隐藏指示层、冻结瞄准点；结束后保留约 0.25 秒缓冲再恢复。已验证 `ImpactCamera` 与剧情回放镜头路径，不保证覆盖所有演出。
