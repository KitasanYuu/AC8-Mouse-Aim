# 问题反馈（Reporting）

## 日志位置

```text
Game/Binaries/Win64/UE4SS/Mods/AC8MouseAim/Logs/MouseAim-xxxxx.log   原生模块日志（每次启动一个文件）
Game/Binaries/Win64/UE4SS/UE4SS.log                                 UE4SS 与 Lua 脚本日志
```

## 提交问题时建议附上

- 模组版本（或仓库提交）、游戏版本。
- CPU、GPU、内存、游戏所在存储设备类型。
- 分辨率、显示模式，以及是否使用其他模组。
- 具体任务与触发情况；卡顿时说明是持续掉帧、单位出现时的停顿，还是镜头或瞄准圈的视觉顿挫。
- 最新的 `MouseAim-xxxxx.log` 与 `UE4SS.log`；如有不加载模组时的对照结果，也请说明。

## 性能统计

1. 进入容易复现问题的任务，按性能统计键（默认 F5）开始统计。
2. 正常游玩，经过一次明显卡顿或敌机出现的时刻。
3. 再按一次结束统计，提供最新的 `MouseAim-xxxxx.log`。

统计约每 10 秒汇总一次，结束时补报剩余数据。不需要同时开启镜头状态采集（默认 F6），它会产生额外的文件操作。

读数说明：`script_wall` 包含 `native_bridge`，两者不能相加；`frame_gap` 包含游戏的其他工作，不等同于模组耗时。统计不测量 GPU 时间，也不能单独证明卡顿原因。

关闭鼠标辅助只停止飞控，不卸载模组，不能作为“完全原版”的性能对照。

## 已知的模组开销

- 遥测开启（`telemetry_port` 非 0）时，他机记录每 3 秒扫描一次游戏对象（约 40 ms），机体几何的自动采集每 5 秒查找一次头目（约 65 ms）。遥测关闭时两者都不运行。
- 机库探测（默认 F7／F8 在机库中）读取全部参数表，只在机库执行。

## 手感问题

摇晃、过冲、拉不起来等问题，请按逐帧飞行记录键（默认 F4）记录发生时的一段，或开启遥测录像（见[飞行重建](../04-development/flight-reconstruction.md)），并说明发生的时间点。
