# 输入与接管（Input & Takeover）

## 瞄准点

- 鼠标的相对移动乘以鼠标灵敏度（`sensitivity`，度／计数），在追尾镜头下绕镜头的上方与右方转动瞄准点。
- 座舱／机首视角下灵敏度按“当前视野角度 ÷ 追尾镜头视野角度”降低，使瞄准圈在画面上移动的速度与追尾镜头一致。
- 瞄准点保存在世界坐标中，飞机转动不会带动它。

## 手动接管

玩家按游戏自己的俯仰、翻滚、平移键时，该轴暂由玩家直接操控，模组不写入该轴；俯仰手动时同时暂停自动翻滚。

判断依据是游戏的 `InputPitch`、`InputRoll`、`InputLeftYaw`、`InputRightYaw`（Lua 每帧读取）：

| 来源 | 取值 |
|---|---|
| 键盘按键 | ±1 |
| 游戏自身的鼠标操控 | 俯仰 ±0.1、翻滚 ±0.2，鼠标移动时出现 |
| 模组写入的杆量 | 不进入这些值 |

游戏自身的鼠标操控只产生约 0.1–0.2 的输入，因此以绝对值 ≥ 0.5 视为玩家操作，避免把游戏的鼠标输入误判为手动接管。按游戏的键位识别，改过键同样有效；手柄摇杆推过一半同样会被识别（未实测）。

## 自动驾驶

- 游戏的自动驾驶在“左右平移输入同时按住”时生效；专用的自动驾驶键（默认 C）由游戏转换为同时按住两个平移输入。它只在按住期间生效。
- 模组在两个平移输入同时 ≥ 0.5 时让出操控与镜头；期间鼠标移动不计入瞄准点。
- 松开的那一帧模组接管，瞄准点回到机首；座舱／机首视角下鼠标摇杆一并回中。

## 让出与恢复

| 情况 | 识别 | 恢复时 |
|---|---|---|
| 注视（长按锁定） | 锁定键按住 ≥ 0.35 秒，或游戏的焦点事件、`ImpactCamera` 激活 | 0.25 秒缓冲后恢复；镜头从游戏视角过渡回来 |
| 剧情演出 | 回放镜头组件、电影模式、输入被忽略 | 同上 |
| 开场等游戏镜头 | 游戏镜头的观察目标不是玩家机体，超过 1 秒 | 瞄准点回到机首 |
| 暂停 | 游戏暂停 | 瞄准点对准画面中心；离机首超过 45° 时对准机首 |
| 机体被放置 | 一帧内位移超过 1 km 且超过 2 km/s | 瞄准点回到机首，飞行路径估计重置 |
| 鼠标辅助关闭 | 开关键（默认 F8） | — |

## 按键

模组的全部按键在 `config.ini` 的 `[keys]` 段，可在调参面板的 Key Config 页录制，保存后即生效；也可写为 `none` 关闭。按键由原生模块统一检测（只在游戏窗口位于前台时生效）；需要 Lua 执行的动作（镜头状态采集、机库探测）以请求的形式交给 Lua。机库探测只在没有玩家机体（机库中）时执行。按键名称的写法见[配置与调参面板](../03-usage/configuration.md#按键)。
