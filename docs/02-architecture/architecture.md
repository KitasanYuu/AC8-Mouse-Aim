# 总体架构（Architecture）

## 组件

| 组件 | 位置 | 作用 |
|---|---|---|
| Lua 主脚本 | `Payload/.../Scripts/main.lua` | 由 UE4SS 加载；每帧在游戏线程读取机体姿态、位置、镜头、游戏输入，调用原生模块，并下发镜头朝向 |
| 追尾镜头脚本 | `Scripts/camera.lua`、`rig_math.lua` | 追尾镜头朝向瞄准点的平滑与翻滚处理 |
| 让出检测 | `Scripts/gaze.lua` | 注视（长按锁定）与剧情演出的识别 |
| 遥测与探测 | `Scripts/contacts.lua`、`mesh_probe.lua`、`spec_probe.lua`、`gaze_probe.lua` | 他机记录、机体几何、机库参数表、镜头状态，均为只读 |
| 原生模块 | `src/` → `ac8_mouse_aim_010.dll` | 鼠标捕获、瞄准点、飞控、输入写入、镜头修正、指示层、调参面板、本地化、日志 |
| 飞控逻辑 | `src/flight_logic.h`、`src/maneuver.h` | 机动选择与杆量整形；同一份代码也编译为开发用 `ac8_flight_logic.dll` |
| 语言文件 | `Scripts/lang/*.txt` | 玩家可见的文字 |

## 每帧数据流

```text
游戏线程
  main.lua 每帧：
    ac8_mouseaim_begin      配置热重载检查、性能计时
    ac8_mouseaim_requests   取回需要由 Lua 执行的按键请求（镜头状态采集、机库探测）
    读取：姿态、镜头、视野角度、位置、暂停、注视、加速/减速、俯仰/翻滚/左右平移输入
    ac8_mouseaim_frame(…)   → 原生模块更新瞄准点并运行飞控，返回追尾镜头的目标朝向
    camera.lua              → ac8_mouseaim_camera 下发追尾镜头朝向
  游戏的输入处理（被挂接）：
    在游戏处理玩家输入时写入俯仰、翻滚、平移轴；玩家手动接管的轴不写入
  游戏的镜头更新（被挂接，更新之后）：
    修正最终画面视角缓存：追尾镜头的位置与朝向，或座舱／机首视角的转头；视野角度增减

其他线程
  鼠标线程：原始输入累计、按键检测、调参面板
  指示层线程：分层窗口，每帧在镜头修正后重绘
  日志线程：有容量限制的队列写盘
```

## 原生挂接点

| 挂接点 | 方式 | 用途 |
|---|---|---|
| `GetRawInputData` | 导入表替换 | 读取鼠标相对移动；不可用时改用 DirectInput |
| 玩家输入处理函数 | MinHook，按特征定位 | 写入操纵轴；只处理玩家机体的调用 |
| PlayerCameraManager 更新 | 虚表槽替换，在原函数之后执行 | 修正最终画面视角缓存（位置、朝向、视野角度） |
| 游戏窗口过程 | 子类化 | 调参面板打开或录键时，不把面板用到的按键交给游戏 |

所有挂接点在启用前校验游戏可执行文件的时间戳、映像大小与关键字节，任一不符即拒绝启用。

## 线程与同步

- 飞控、镜头修正、Lua 调用都在游戏线程；原生模块只接受来自同一线程的帧数据。
- 鼠标线程与游戏线程之间只交换原子量（鼠标累计量、按键状态、开关）。
- 调参面板写 `config.ini` 时先写临时文件再整体替换，热重载不会读到半个文件；写入后下一帧即重新读取。

## 配置与热重载

- `config.ini` 由 `[control]`（操作、镜头、显示）、`[keys]`（按键）、`[tuning]`（飞控）三段组成，详见[配置与调参面板](../03-usage/configuration.md)。
- 原生模块每 0.5 秒检查文件修改时间，变化即重新读取；飞控逻辑同时重新配置。
- 开发用 `ac8_flight_logic.dll` 存在时，修改后约 1 秒内热加载；接口版本（`logic_abi`）不符则拒绝。

## 本地化

文字按编号从当前语言文件读取，缺失时使用代码中的英文；语言跟随游戏（Lua 读取引擎当前语言）或由设置指定。详见[多语言](../03-usage/localization.md)。
