# 飞控规范（Flight Control）

本文件定义鼠标辅助“应当怎样飞”。实现位于 `src/maneuver.h`（机动选择）与 `src/flight_logic.h`（杆量整形）；参数在 `config.ini` 的 `[tuning]` 段，表中默认值即仓库与游戏中安装的配置值。行为规则修改应先改本文件，并通过 `dev\check.cmd` 中的闭环仿真。

## 原则

1. **对齐 War Thunder 鼠标指向**：鼠标给出世界方向，飞机以实际最快的翻滚／俯仰组合把机首带过去。不内置具名机动库，破 S、殷麦曼、斜筋斗、直接下压等都是同一规则在不同瞄准点方位下的结果。
2. **执行意图，不替玩家做决定**：不设禁止项，不做防撞地、防失速、过载限制或倒飞限制。ACE 系列机体性能超出现实战斗机，不得以“保护”为由削减杆量。
3. **按实测机体决策**：拉杆还是推杆、是否先翻正，按实测模型估算的用时比较，不用人为偏好。
4. **只在几何歧义处做选择**：规则只在数学上无法唯一确定方向时给出偏好，并用滞回避免来回翻转。

## 实测机体模型

2026-10-03 标定（Build 25201480），参数见 `config.ini` `[tuning]` 开头部分：

| 轴 | 延迟 | 游戏输入平滑 | 动态 | 满杆能力 | 输入曲线 |
|---|---|---|---|---|---|
| 俯仰 | 0.24 s | 加杆 0.36 s，回中 0.10 s | 一阶，时间常数 0.40 s | 拉 61°/s、推 17°/s（正飞时推杆另加 `push_gravity` 6.5°/s） | 约 \|u\|^1.1 |
| 翻滚 | 0.16 s | 0.06 s | 加速度受限 220°/s²，时间常数 0.8 s | 上限 150°/s | 加速度约 \|u\|^1.3 |

重力项 `pitch_gravity`（0.3）：正飞回中杆时游戏基本保持机首，实测约 1900 帧中位 −0.2°/s。游戏版本变化后应重新标定（`calibrate`）。

### 按机型在线辨识

默认关闭（`ident_memory=0`），按标定模型飞行。开启时：一组候选模型（权限倍率 × 响应时间常数 × 额外延迟）用实际发出的杆量并行运行，取近期与实测角速度最吻合者，接近的候选按代价加权平均；累计 `ident_trust` 秒数据前按标定值飞行。手动接管期间不学习；暂停、回中等重置时保留辨识结果，换机时重置。

## 量的定义

机体坐标：前 `f`、右 `r`、上 `u`。瞄准点在机体系的分量为 `fx, rx, ux`。

| 量 | 定义 | 含义 |
|---|---|---|
| θ | `acos(fx)` | 机首与瞄准点的夹角 |
| 拉杆翻滚角 | `atan2(rx, ux)` | 使瞄准点位于座舱正上方所需的翻滚，正值向右 |
| 推杆翻滚角 | `atan2(-rx, -ux)` | 使瞄准点位于机腹正下方所需的翻滚 |
| 俯仰面误差 | `atan2(ux, fx)` | 瞄准点在机体俯仰平面内的角度，可超过 90° |
| 横向误差 | `atan2(rx, fx)` | 方向舵修正量 |

## 机动选择

任何距离都用同一条规则，每帧按当前几何重新决定，不锁定机动；唯一的记忆是二选一处的滞回（拉／推、±180° 翻滚方向、受限升力保持在哪一侧、正后方掉头方向）。

### 统一规则

- **翻滚**：让座舱（拉杆）朝向瞄准点；瞄准点接近机腹正下方时让机腹朝向它（推杆）。
- **坡度上限**（相对地平线）：
  - 拉杆时坡度最多 `slice_bank`（90°）；离瞄准点 `slice_from`～2×`slice_from`（20°～40°）之间放宽到 `slice_deep`（135°，斜切）；离瞄准点 `invert_min_angle`（120°）起再放宽，150° 时可倒飞（破 S）。小幅的左下／右下修正因此是“翻滚 + 拉杆 + 方向舵”，不会机腹朝上。
  - 已经压着的大坡度不会被一下砍到上限，而是允许“当前坡度 − `slice_ease`”（最多 `slice_hold`），逐步放平。
  - 接近瞄准点时改平：坡度最多为（剩余角度 − `level_inside`）× `level_per_deg`。默认离瞄准点 5° 时最多 40°，2° 时 10°，1° 以内保持机翼水平。
  - `chase_level=1` 时，瞄准点持续移动（追击）不受上述改平上限。默认 0：上限放开时，瞄准点附近每一下鼠标移动都会让坡度整圈来回（2026-10-07）。
- **推杆**：满足任一条件即推杆：
  - 瞄准点离拉杆可用的（受限）升力方向超过 `push_below`（60°，退出 45°）：机翼回正、机腹朝向瞄准点。
  - 瞄准点接近机腹正下方（推杆所需翻滚小于 `push_roll_enter`），且按估算用时推杆更快。倒飞时推杆能力几乎为零，会半滚后拉杆。
  - 瞄准点持续移动（超过 `pursuit_speed`）时不用第一条，以免下降转弯的目标被改成推杆。
- **俯仰**：与翻滚同时开始。按“杆量生效时翻滚已到达的姿态”计算：翻滚预计在俯仰延迟内完成的部分（最多 `overlap_max`，离瞄准点 15° 内逐步取消、5° 内为 0）算作已完成。远处（≥ `far_start`）按升力方向上的角度乘以对准程度的余弦拉杆，近处（≤ `near_end`）按座舱方向的偏差，可推杆。
- **方向舵**：负责俯仰平面以外的部分：近处是机翼方向的偏差，转弯中是受限升力平面以外的部分。

### 正后方歧义（θ > 160° 进入，θ < 145° 退出）

瞄准点几乎正对机尾时，翻滚方向对鼠标微小抖动极度敏感。此时采用斜向上掉头：翻滚使升力方向位于“世界上方偏向一侧 `tail_bank`（50°）”，然后满杆拉；偏向哪一侧取进入时瞄准点所在的左右侧，锁定到退出。机首接近垂直时保持当前翻滚直接拉。

### 低空下沉时的拉起方式

按当前下沉率 `ground_guard` 秒内会到海平面、瞄准点高于机首、且座舱偏离天空超过 `escape_bank`（90°）时：先沿最短方向把座舱转向天空，再拉杆。只在瞄准点不低于地平线 `escape_aim_down`（10°）以下时生效：瞄准点放得更低是玩家要求的俯冲。只改变到达方式，瞄准点仍由玩家决定。高度为海拔，山地上空不起作用。

### 精细选杆

瞄准点在 `fine_angle`（20°）以内时，把几组候选的翻滚与方向舵杆量（规则给出的、不翻滚的、两侧小幅偏移的）用机体模型从在途指令生效后的状态往前模拟 `fine_horizon`（1 秒），按瞄准误差、翻滚角速度、坡度和杆量变化打分，飞代价最低的一组。俯仰仍由规则决定（`fine_pitch=0`）。`fine_to_go` 计入视距之后剩余误差的消除用时，`fine_follow` 让模拟中的俯仰随规则变化；没有这两项时，回报超过 1 秒的翻滚永远不会被选，目标会绕机首打转。低空拉起生效时让出。

### 高G力回转

按住高G力回转时，俯仰拉杆能力按 `highg_pull`（1.4 倍）估计；瞄准点偏离超过 `highg_full_from`（8°）且在升力一侧时直接满拉，不提前减速。

### 失速机动辅助

由高G力回转进入失速机动时，游戏要求“按下高G力回转那一刻俯仰没有在拉杆，且随后的拉杆落在高G力回转按住期间”（低于 500 km/h）。飞控只要瞄准点偏离就会拉杆，因此按住失速机动辅助键时：按下高G力回转后的 0.04 秒俯仰回中，随后在 0.3 秒内满拉。之后照常飞向瞄准点；翻转中按机首惯性提前回中。能否进入取决于机型。座舱／机首视角下，按住期间瞄准点改为世界方向（不随鼠标摇杆）。

## 杆量整形

每轴每帧：

1. **延迟预测**：用模型回放最近一个延迟时长内已发出、尚未体现在角速度上的指令，得到延迟后的角速度及期间转过的角度，用剩余误差决策。
2. **期望角速度**：取三者最小值：满杆能力 ×0.9、按反向能力仍能在瞄准点停住的最大角速度（`*_brake` 为制动能力系数）、剩余角度 × `*_gain`。按实测模型，俯仰由“剩余角度 × `pitch_gain`”决定，`pitch_brake` 实际不起作用；翻滚则由制动项决定。
3. **模型反解**：按模型反解所需杆量，经实测输入曲线换算。`pitch_unload`（0.3）：减缓仍需的俯仰时，最多用三成反向杆量，而不是满杆推杆刹车。
4. **俯仰配平**：近处对小误差积分（`pitch_trim`），机动中保留（`pitch_trim_keep=1`）。
5. **角速度观测器**：用模型推算、以 `rate_observer`（1/s）向实测值校正的估计值代替带噪声的实测值。
6. **实时舵效估计**：按 `authority_memory` 秒遗忘做最小二乘，得到俯仰和翻滚的舵效倍率，只采纳变化的 `authority_trust`，限制在 `authority_min`–`authority_max`。
7. **移动瞄准点补正**：瞄准点在机首俯仰／平移方向上的移动速度经 `lead_filter` 秒低通，乘以 `lead_gain` 叠加到期望角速度（最多 `lead_max`）。`lead_gate=1` 时，必须先翻滚的阶段只保留顺着即将到来的拉杆方向的部分。

手动接管与自动驾驶的识别见[输入与接管](input-and-takeover.md)。

## 调参入口

| 参数 | 默认 | 作用 |
|---|---|---|
| `near_end` / `far_start` | 3° / 20° | 远处按升力方向拉杆，近处按座舱／机翼方向的偏差，之间平滑过渡 |
| `level_per_deg` / `level_inside` | 10 / 1° | 改平：坡度最多为（剩余角度 − 1°）× 10 |
| `chase_level` | 0 | 1：追击移动瞄准点时不受改平上限 |
| `pursuit_ahead` | 0.3 s | 翻滚朝向被追目标 0.3 秒后的位置 |
| `upright` | 0 | 不偏好正飞（推杆选择仍让小幅向下修正保持正飞） |
| `slice_bank` / `slice_deep` / `slice_from` | 90° / 135° / 20° | 拉杆坡度上限 |
| `invert_min_angle` | 120° | 离瞄准点超过此角度才允许更深的坡度 |
| `slice_ease` / `slice_hold` | 10° / 135° | 已压着的大坡度逐步放平 |
| `push_below` / `push_below_exit` | 60° / 45° | 瞄准点离可用升力超过此角度时改为推杆 |
| `push_roll_enter` / `push_roll_exit` | 30° / 50° | 瞄准点接近机腹正下方时才考虑推杆 |
| `push_enter` / `push_exit` | 120° / 135° | 允许推杆的误差范围（滞回） |
| `choice_margin` / `push_bias` | 0.6 s / 0 | 推杆比拉杆慢多少仍可选 / 推杆偏好 |
| `pursuit_speed` | 4°/s | 瞄准点移动快于此值视为追击 |
| `overlap_max` | 30° | 翻滚中提前拉杆时最多计入的未完成翻滚 |
| `tail_enter` / `tail_exit` / `tail_bank` | 160° / 145° / 50° | 正后方掉头 |
| `latch_limit` | 150° | ±180° 翻滚方向锁定的释放阈值 |
| `ground_guard` / `escape_bank` / `escape_aim_down` | 8 s / 90° / 10° | 低空下沉时的拉起方式（0 = 关闭） |
| `fine_search` / `fine_to_go` / `fine_follow` / `fine_pitch` | 1 / 3 / 1 / 0 | 精细选杆（0 = 只用规则） |
| `highg_pull` / `highg_full_from` | 1.4 / 8° | 高G力回转 |
| `pitch_gain` / `roll_gain` | 2.5 / 2.0（1/s） | 接近瞄准点时的收敛速度；俯仰超过 4 会在瞄准点附近来回修正 |
| `pitch_gain_near` | 0.4 | 最后约 4° 内俯仰增益提高到 1.4 倍 |
| `pitch_brake` / `roll_brake` | 0.45 / 0.45 | 制动能力系数；翻滚越小越早减速 |
| `pitch_kd` / `roll_kv` | 0.1 / 1.5 | 角速度跟踪 |
| `pitch_unload` | 0.3 | 减缓俯仰时最多使用的反向杆量比例 |
| `lead_gain` / `lead_filter` / `lead_max` / `lead_gate` | 1.0 / 0.4 s / 60°/s / 1 | 移动瞄准点补正 |
| `pitch_trim` / `pitch_trim_limit` / `pitch_trim_keep` | 1.0 / 4°/s / 1 | 俯仰配平 |
| `rate_observer` | 3 | 角速度观测器 |
| `authority_memory` / `authority_filter` / `authority_trust` / `authority_min` / `authority_max` | 2 s / 1 s / 0.6 / 0.35 / 2.0 | 实时舵效估计（`authority_memory=0` 关闭） |
| `ident_memory` / `ident_trust` | 0 / 3 s | 按机型在线辨识（0 = 关闭） |
| `rollout_rate` / `rollout_lag` | 0 / 0.25 s | 可选：按到达用时限制坡度（默认关闭） |
| `calibrate` | 0 | 改为新的正数即运行一次输入标定 |
| `maneuver_test` | 0 | 改为新的正数即开始失速机动测试计划 |
| `auto_trace` | 0 | 1：每次机动写 `AT` 记录；2：每一帧 |

## 诊断记录

- 逐帧飞行记录（默认 F4）：日志中的 `TRACE` 行，含误差、角速度、杆量、实际写入值和手动接管状态。
- 自动机动记录（`auto_trace`）：机首偏离瞄准点超过 4° 时开始，1° 以内持续 2 秒后停止，每帧一行 `AT`：帧间隔、θ、对准权重、正后方、推杆、俯仰误差、翻滚误差、坡度、俯仰／翻滚角速度、俯仰／翻滚杆量、期望与预测的俯仰／翻滚角速度、手动接管位、必然俯仰、俯仰／翻滚舵效倍率。
- 日志每 10 秒记录一行 `guidance`；在线辨识开启时每 5 秒一行 `ident:`。
