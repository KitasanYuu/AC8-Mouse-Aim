item.sensitivity = Mouse Sensitivity
item.sensitivity.desc = Sets how far the aim turns per mouse count (deg). Lower in the cockpit and nose views, in proportion to their field of view.

item.camera_follow = Camera Tracking Speed
item.camera_follow.desc = Sets how fast the chase camera turns toward the aim (1/s). Higher keeps the camera closer to the aim.

item.camera_distance = Camera Distance
item.camera_distance.desc = Sets the chase camera's distance behind the aircraft (m). 0 uses the game's own distance and height.

item.camera_height = Camera Height
item.camera_height.desc = Sets the chase camera's height above the aircraft (m). Not used when Camera Distance is 0.

item.free_look_keep = Free Look Keeps Aim
item.free_look_keep.desc = Sets where the aim goes when free look ends. OFF: back where it was  ON: the ring follows the camera during free look and the aim moves there on release (as in War Thunder)

item.camera_fov_add = Field of View Offset
item.camera_fov_add.desc = Degrees added to the game's field of view in the chase view. The game's changes with speed are kept.

item.near_view_camera = View Mode
item.near_view_camera.desc = Sets the camera in the cockpit and nose views. 0: fixed ahead  1: turns to the aim  2: turns once the aim passes the edge  3: fixed ahead, the head turns toward the ring

item.near_view_follow = Head Turn Ratio
item.near_view_follow.desc = Mode 3 only. Sets how far the view turns toward the ring, as a share of the ring's offset (0-1).

item.near_view_hud = Head Turn Limit
item.near_view_hud.desc = Mode 3 only. The view turns at most half the screen plus this many degrees, so the HUD's edge stays on screen.

item.near_view_mouse = Mouse Multiplier
item.near_view_mouse.desc = Modes 0 and 3 only. Sets the mouse movement multiplier for the cockpit mouse stick.

item.near_view_expo = Ring Curve
item.near_view_expo.desc = Modes 0 and 3 only. The ring moves as the stick deflection to this power: 1 is linear, higher is finer near the nose.

item.near_view_inertia = View Delay
item.near_view_inertia.desc = Sets how far the view lags the aircraft's attitude (s). 0 is no delay.

item.near_view_level = View Leveling
item.near_view_level.desc = Sets how much of the view's roll is corrected toward level. 0: rolls with the aircraft  1: stays level

item.near_view_fov_add = Field of View Offset
item.near_view_fov_add.desc = Degrees added to the game's field of view in the cockpit and nose views.

item.pitch_gain = Pitch Gain
item.pitch_gain.desc = Sets the pitch speed near the aim: wanted pitch rate = this x the angle left (1/s). Higher arrives faster; too high corrects back and forth near the aim.

item.roll_brake = Roll Deceleration
item.roll_brake.desc = Sets the deceleration planned for stopping a roll, as a share of the aircraft's roll acceleration. Lower starts slowing earlier.

item.level_per_deg = Level Recovery
item.level_per_deg.desc = Near the aim, bank is limited to this x the angle left. Lower returns the wings to level sooner.

item.lead_gain = Moving Aim Correction
item.lead_gain.desc = Sets the share of a moving aim's angular rate added to the turn. 0 is off.

item.lead_filter = Correction Smoothing
item.lead_filter.desc = Sets the smoothing time used to estimate the aim's angular rate (s).

item.highg_full_from = High-G Full Pull Angle
item.highg_full_from.desc = During a High-G Turn with the aim more than this far off, the stick is pulled fully without slowing early (deg). 0 is off.

item.status_line = Status Display
item.status_line.desc = Sets whether the version, state and angles are shown at the top left of the screen.

item.language = Language
item.language.desc = Sets the language of this panel and the mod's on-screen text. Auto: the game's UI language.

item.toggle = Mouse Aim ON/OFF
item.toggle.desc = Sets the key that turns mouse aim on and off. When off, the game's own controls fly the aircraft.

item.recenter = Reset Aim
item.recenter.desc = Sets the key that returns the aim to where the nose points.

item.free_look = Free Look
item.free_look.desc = Sets the key that, while held, lets the mouse move only the camera. The aim is kept.

item.hud = Mod HUD ON/OFF
item.hud.desc = Sets the key that shows or hides the mod's rings. Flight control is unaffected.

item.post_stall = Post-Stall Assist
item.post_stall.desc = Sets the key for post-stall assist. While it is held, the pitch input during a High-G Turn is adjusted to meet the post-stall condition.

item.tuning = Settings Panel
item.tuning.desc = Sets the key that opens and closes this panel.

item.tuning_up = Previous Item
item.tuning_up.desc = Sets the key that selects the previous item.

item.tuning_down = Next Item
item.tuning_down.desc = Sets the key that selects the next item.

item.tuning_less = Decrease
item.tuning_less.desc = Sets the key that decreases the value.

item.tuning_more = Increase
item.tuning_more.desc = Sets the key that increases the value.

item.tuning_fine = Fine Adjustment
item.tuning_fine.desc = Sets the key that, while held, adjusts in steps of 1/5.

item.tuning_undo = Restore
item.tuning_undo.desc = Sets the key that restores the value from when the panel was opened.

item.tuning_bind = Change Key
item.tuning_bind.desc = Sets the key that records a new key for the selected item on the Key Config page.

item.reload = Reload Settings
item.reload.desc = Sets the key that reads config.ini again.

item.trace = Flight Log
item.trace.desc = Sets the key that turns the per-frame flight log on and off.

item.perf = Performance Statistics
item.perf.desc = Sets the key that turns performance statistics on and off (written to the log every 10 s).

item.camera_probe = Camera State Capture
item.camera_probe.desc = Sets the key that starts or stops capturing the camera state (up to 180 s).

item.hangar_specs = Hangar: Aircraft Data
item.hangar_specs.desc = Sets the key that, in the hangar, writes the aircraft's parameter tables to a file.

item.hangar_geometry = Hangar: Aircraft Geometry
item.hangar_geometry.desc = Sets the key that, in the hangar, writes the aircraft's geometry to a file.
