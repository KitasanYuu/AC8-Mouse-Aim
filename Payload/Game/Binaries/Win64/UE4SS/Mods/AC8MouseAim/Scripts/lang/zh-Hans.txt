item.sensitivity = 鼠标灵敏度
item.sensitivity.desc = 指定以鼠标操作瞄准点时的灵敏度（每个鼠标计数转动的角度）。座舱／机首视角下按视野角度（FOV）的比例降低。

item.camera_follow = 镜头追踪速度
item.camera_follow.desc = 设置追尾镜头转向瞄准点的速度（1/秒）。数值越大，镜头越贴近瞄准点。

item.camera_distance = 镜头距离
item.camera_distance.desc = 设置追尾镜头与机体的距离（m）。设为 0 时使用游戏本身的距离与高度。

item.camera_height = 镜头高度
item.camera_height.desc = 设置追尾镜头在机体上方的高度（m）。镜头距离为 0 时无效。

item.free_look_keep = 自由视角后保持朝向
item.free_look_keep.desc = 设置解除自由视角时瞄准点的位置。OFF：回到进入自由视角前的位置　ON：自由视角期间瞄准圈跟随镜头，解除时瞄准点移到镜头所朝的方向（同 War Thunder）

item.camera_fov_add = FOV 修正
item.camera_fov_add.desc = 在游戏的视野角度（FOV）上增减的度数（追尾镜头）。保留游戏随速度产生的变化。

item.near_view_camera = 视角模式
item.near_view_camera.desc = 设置座舱／机首视角的镜头动作。0：固定朝前　1：朝向瞄准点　2：瞄准点到达画面边缘才转动　3：固定朝前并朝瞄准圈转头

item.near_view_follow = 转头比例
item.near_view_follow.desc = 模式 3 专用。设置视角朝瞄准圈方向转动的比例（0～1）。

item.near_view_hud = 转头上限
item.near_view_hud.desc = 模式 3 专用。视角最多转到半个画面再加上该角度，使 HUD 边缘保留在画面内。

item.near_view_mouse = 鼠标倍率
item.near_view_mouse.desc = 模式 0／3 专用。设置座舱鼠标摇杆的鼠标移动倍率。

item.near_view_expo = 瞄准圈曲线
item.near_view_expo.desc = 模式 0／3 专用。瞄准圈的位置为摇杆量的该次方。1 为线性，数值越大，机首附近越精细。

item.near_view_inertia = 视角延迟
item.near_view_inertia.desc = 设置视角跟随机体姿态的延迟（秒）。0 为无延迟。

item.near_view_level = 视角水平修正
item.near_view_level.desc = 设置视角的翻滚向水平修正的比例。0：随机体翻滚　1：保持水平

item.near_view_fov_add = FOV 修正
item.near_view_fov_add.desc = 在游戏的视野角度（FOV）上增减的度数（座舱／机首视角）。

item.pitch_gain = 俯仰增益
item.pitch_gain.desc = 设置接近瞄准点时的俯仰速度：目标俯仰角速度＝该值×剩余角度（1/秒）。数值越大越快到位，过大会在瞄准点附近反复修正。

item.roll_brake = 翻滚减速
item.roll_brake.desc = 设置翻滚停止时预计使用的减速度（占机体翻滚加速度的比例）。数值越小，越早开始减速。

item.level_per_deg = 水平恢复
item.level_per_deg.desc = 接近瞄准点时，坡度上限＝该值×剩余角度。数值越小，机体越早回到水平。

item.lead_gain = 移动瞄准点补正
item.lead_gain.desc = 设置追随移动中的瞄准点时，追加其角速度的比例。0 为关闭。

item.lead_filter = 补正平滑
item.lead_filter.desc = 设置估算瞄准点角速度时的平滑时间（秒）。

item.highg_full_from = 高G力满拉角度
item.highg_full_from.desc = 进行高G力回转且瞄准点偏离超过该角度时，直接将操纵杆拉满，不提前减速（度）。0 为关闭。

item.status_line = 状态显示
item.status_line.desc = 设置是否在画面左上角显示版本、状态与角度。

item.language = 语言
item.language.desc = 设置本面板与 MOD 画面文字的语言。自动：跟随游戏的 UI 语言。

item.toggle = 鼠标辅助 ON/OFF
item.toggle.desc = 设置用于切换鼠标辅助的按键。OFF 时由游戏原本的操作控制机体。

item.recenter = 瞄准点复位
item.recenter.desc = 设置使瞄准点回到机首方向的按键。

item.free_look = 自由视角
item.free_look.desc = 设置按住时只以鼠标操作镜头的按键。瞄准点保持不变。

item.hud = MOD 指示 ON/OFF
item.hud.desc = 设置切换 MOD 瞄准圈显示的按键。飞行控制不受影响。

item.post_stall = 失速机动辅助
item.post_stall.desc = 设置失速机动辅助的按键。按住期间进行高G力回转时，调整俯仰杆量以达成失速机动的条件。

item.tuning = 设置面板
item.tuning.desc = 设置用于打开或关闭本面板的按键。
