# Scenes with recorded enemies for the comparison bench (harness.cpp reads this list; the
# scripted scenes are defined in harness.cpp). Only the enemies are taken from the recording:
# they fly their recorded paths, and every controller meets them with the same simulated
# player from the same standard start (1.5 km behind), on every condition.
# Cut new enemies with extract_tracks.py (one enemy, tracks/) or extract_battles.py (several,
# battles/), or overlay the busiest recorded fights with synth_battles.py (battles/synth_<n>.txt),
# then add a line here.
#
#   kind    landing (landings/, cut with extract_landings.py), multi (several, battles/), boss
#           (battles/, cut with --boss); single (one enemy,
#           tracks/) is still read but no longer used: the boss fights cover it
#   file    the cut file
#   id      <category>_<nn>: multi_, boss_
#   title   <category> · <what>; may begin with start=<m>: start that far behind the enemy, or
#           start=player: as the player was at the cut (attitude and speed; a phase following another)
#           target=game: the enemy the player had locked at each moment chased (the pilot's own choice while none)
#           from=<s>: the scene starts that far into the file (with start=player: as the player was then)
#           instead of the standard distance (single 1 km, multi 1.5 km, boss 800 m), and with
#           order=game|near|nose|mixed: every controller attacks in the same fixed order (the
#           player's own, or a reference flight's; see reference_order in harness.cpp). The
#           crowded M28 battle runs in the player's own order only (four orders until 2026-10-06);
#           and missiles=1|laam: missiles as well as the gun, by the old rules or LAAMs flown
#           (fights are gun only otherwise).
#
